# Security Policy

## Supported Versions

Security fixes are prioritized for the latest published version of `@zentauri-ui/zentauri-components`.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Report security concerns through one of these private channels:

- Open a private security advisory on GitHub for `ShubhamTiwari909/zentauri-ui`.
- Email `shubhamtiwari00@gmail.com` with a short description, affected package/version, reproduction steps, and impact.

We will acknowledge valid reports as soon as possible and coordinate a fix, release, and disclosure timeline based on severity.

## Scope

In scope:

- Published package code in `packages/components`
- The package CLI in `packages/components/cli`
- Documentation or examples that could lead users to unsafe production configuration

Out of scope:

- Social engineering
- Denial-of-service reports that rely only on excessive traffic
- Vulnerabilities in consumer applications that vendor or modify Zentauri UI source
